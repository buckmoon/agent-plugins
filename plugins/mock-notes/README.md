# Mock Notes（mock-notes）

HTML の UI モックの画面の上に、「何が変わったか」「何が決まっていないか」「何を仮に置いたか」の注記を浮かべるスキルと部品です。フィードバックを受けてAIがモックの次の版を作るとき、変えた箇所ごとに注記を付けさせます。読む人は、モックを触りながら変更点と未決事項を確かめられます。

## 目指す状態

- 読む人が、モックを開いただけで、前の版からの変更点と、自分が決めるべきことに気づける
- どのモックでも注記の見た目と操作が同じで、読む人が見方を覚え直さずにすむ
- AIが、意見の分かれた点を勝手に決めず、頼まれていない追加を黙って入れない。どちらも注記で読む人に返す
- 読む人の返事（「#3 は〜で」）を、AIがそのまま次の版に反映できる

## できること

- **3種類の注記**：修正済み（緑）、要解決（赤。人ごとの意見を並べる）、要確認（橙。作り手が仮に置いた内容）
- **浮かぶ注記**：対象の右肩にリーフ（しずく形の印）が付き、矢印でカードにつながります。カードはドラッグで動かせ、リーフを押すと開閉します。動かした位置と閉じた状態は、ブラウザに保存されます。
- **注記の一覧**：画面の左下の帯から開きます。一覧で注記を押すと、左メニューやタブを押してそこへたどり着くまでの手順を、カーソルの動きで再生します。
- **文字で書き出す**：注記をまとめて文字にし、Slack や AI に貼れます。
- **検証**：`MockNotes.verify()` で、全注記の開き方と対象を確かめます。

部品（`skills/mock-notes/mock-notes.js`）は外部のファイルも通信も使いません。モックの HTML に貼れば、ファイル1つで配れます。動く見本は `skills/mock-notes/example.html` です。

## 使う

モックを直す依頼に「mock-notes で注記を付けて」と添えます。フィードバックを受けた次の版では、AIがフィードバックに番号を振り、変えた箇所ごとに注記を書き、検証してから渡します。

## 注意

- 注記の位置は、対象を CSS セレクタで指して決めます。モックの作りを大きく変えると、注記が対象を見失うことがあります。渡す前に `verify` を通してください。
- `verify` は画面を実際に操作します。データを書き換える手順があるモックでは、初期化してから実行してください。
