# 送るもの・残るもの・かかる利用量

grip-for-readers の試し読みフックは、AIが書いた下書きを出す前に、読み手の立場の別のAIに読ませる仕組みである。読み手が引っかかる文があれば、その書き込みや投稿を拒んで（以下「止める」）、AIに質問を返して書き直させる。この文書は、このフックがどこに何を送り、手元に何を残し、どれだけ利用量を使うかをまとめたものである。入れる前に読んで、自分の環境で使ってよいかを判断してほしい。版 0.1.0 時点の内容である。

## どこに何を送るか

試し読みは、利用者が使っているAIのコマンドを、フックから呼び出して行う。Claude Code では `claude -p`、Codex では `codex exec` で、どちらも利用者のアカウントで動く。送り先は、利用者がふだんそのAIを使うときと同じ提供元（Anthropic または OpenAI）で、それ以外の場所には送らない。

送る内容は、読み手によって変わる。読み手は下書きのファイル名の先頭で決まる。たとえば `slack-20260925-1430.md` なら Slack の読み手、`20260925-1430.md` のように先頭に何も付けなければ依頼者として読む。先頭の種類は `slack-`・`email-`・`github-`・`doc-` の4つで、一覧は [design.md](design.md) の「読み手の種類」にある。

| 読み手 | 送る内容 |
|---|---|
| 依頼者（ファイル名の先頭なし） | 下書きの全文と、その会話で依頼者が見たもの（依頼者の発言とAIの本文。最大3万字で、それを超えると古いほうから削る）。道具の入出力と、作業中に読んだファイルは送らない。会話の内容は送るだけで、手元の記録には残さない |
| Slack・メール・GitHub・文書 | 下書きまたは投稿の本文だけ |

## かかる利用量と待ち時間

試し読み役が呼ばれるのは、次の二つのときだけである。ほかのファイルへの書き込みでは呼ばれない。

- AIが一時フォルダの `grip-for-readers-drafts/` に400字以上の下書きを書き込むとき
- AIが GitHub の MCP の道具で、400字以上の本文を issue や PR に投稿するとき

止められて書き直すと、書き直した版でもう1回呼ばれる。止めるのは同じ依頼の中で読み手ごとに1回だけなので、書き直した版は止められない。ふつうは文章1本あたり1〜2回で、AIがさらに下書きを書き直すと、そのたびに1回ずつ増える。

作者の環境では、1回に4〜15秒かかった。この間、書き込みや投稿は待たされる。呼び出しが150秒を超えるか失敗したときは、止めずに通す。

モデルは次のとおり決まる。

- Claude Code：利用者の既定のモデル
- Codex：Codex の既定のモデル。利用者の `~/.codex/config.toml` のモデル設定は使わない。試し読み役の中でフックがもう一度動かないよう、利用者の設定を読まずに起動しているためである

どちらも、環境変数 `GRIP_FOR_READERS_MODEL` にモデル名を入れると、そのモデルを使う。

## 手元に残るもの

記録は、Claude Code では `~/.claude/grip-for-readers/`、Codex では `~/.codex/grip-for-readers/` に残る。環境変数 `GRIP_FOR_READERS_HOME` で場所を変えられる。どれも自動では消えないので、要らなければ消してよい。

| ファイル | 中身 | いつ増えるか |
|---|---|---|
| `log.jsonl` | 試し読みした文章の全文、判定（引っかかった文と質問）、かかった秒数、止めたか | 試し読みのたび |
| `log.jsonl` | 依頼者への400字以上の報告の字数と、その報告が先に下書きとして試し読みを通ったか（報告の本文は残さない）。grip-for-readers スキルの手順（先に下書きを書いて試し読みを通す）がどれだけ守られているかを見るための記録で、通っていなくても何も起きない | AIが応答を書き終えるたび |
| `state.json` | 止めたことの記録（会話と依頼の識別子だけ） | 止めたとき。最新の200件だけ残す |
| `last_drafts.json` | 依頼者向けの最後の下書きの冒頭200字 | 依頼者向けの下書きを書いたとき。最新の200会話分だけ残す |

下書きそのものは、一時フォルダ（環境変数 `TMPDIR` の場所。空なら `/tmp`）の下の `grip-for-readers-drafts/` に残る。一時フォルダは OS が掃除することがあるが、いつ消えるかは OS による。

## 止める・調整する

| 環境変数 | 効果 |
|---|---|
| `GRIP_FOR_READERS=0` | 試し読みも記録もしない |
| `GRIP_FOR_READERS_MIN_CHARS` | 試し読みする字数の下限（既定は400） |
| `GRIP_FOR_READERS_MODEL` | 試し読み役のモデル |
| `GRIP_FOR_READERS_HOME` | 記録を置く場所 |

環境変数は、Claude Code や Codex を起動する前のシェルで設定する。プラグインごと止めるときは、それぞれの道具でプラグインを無効にする（[install-claude.md](install-claude.md)、[install-codex.md](install-codex.md)）。
